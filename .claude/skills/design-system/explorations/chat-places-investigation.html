2 · Map style — Mapbox vs Google Maps Embed

Same pins, same data. The question is how much we can brand the map. Pins encode the NQS rating in teal (our differentiator), with the star score as the label.

Mapbox

Fully brandable. Warm light palette to match Kindello, custom teal NQS pins, hide clutter. Costs per map load (free tier ~50k/mo), needs a token + a JS map lib. Best for the standalone site.

B · Google Maps Embed

Rozelle Pyrmont Annandale
Google

Free & instant (iframe, no token), but you get Google's stock palette and red markers you can't restyle or label — no NQS colour, no warmth, no custom pins. Fine for a single embedded pin on a detail page; weak for a branded results map.
