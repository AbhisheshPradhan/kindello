**Button** — Kindello's action primitive; teal primary, coral accent for high-intent CTAs.

```jsx
<Button variant="accent" size="lg">Enquire</Button>
<Button variant="outline" iconLeft={<MapPin/>}>Directions</Button>
```

Variants: `primary` (teal), `accent` (coral, glows), `secondary`, `outline`, `ghost`. Sizes: `sm` `md` `lg`. `full` stretches to width. Pass `iconLeft`/`iconRight` as Lucide nodes.
