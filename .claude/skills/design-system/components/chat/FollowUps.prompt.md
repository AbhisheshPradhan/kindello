**FollowUps** — suggested next questions under an answer.

```jsx
<FollowUps items={[
  "Which of these have vacancies for toddlers?",
  "What's the typical weekly fee after the subsidy?",
]} onSelect={ask} />
```

Corner-return arrow + hairline dividers, Perplexity-style. Tapping appends the next conversation turn. **Answer tab only** — never on Places.
